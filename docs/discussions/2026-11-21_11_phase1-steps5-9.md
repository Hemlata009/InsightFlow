## Decisions made during the build
1. **Derive formulas live in the config** (`derive_expression`), not in code. Expressions may only use
   column names, numbers and `+ - * / ( )`, and are validated at load time.
2. **New generic conflict checks** in the rule book: not nullable + keep_and_flag; derive without a
   formula / with unknown columns / referring to itself; empty allowed list; normalize_case on non-text columns.
3. **No domain names in core code.** Enforced by a test (`test_core_code_has_no_domain_column_names`).
   "Losses allowed" and "returns allowed" are expressed as column min/max in the dataset config.
4. Flags only count for rows we keep (a quarantined row's extra flags stay in the log).
5. Exact duplicates are removed (policy `drop`) but saved in `duplicates_removed.csv` with the row they
   duplicate, so nothing disappears.
6. A spelling with no other occurrence keeps its form (no guessing of capitals).
7. Invisible non-breaking spaces are standardized to normal spaces.

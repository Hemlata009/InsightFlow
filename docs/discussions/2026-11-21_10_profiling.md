# 2026-11-21 · Discussion 10: Step 4, profiling (health check)

## Request
"Yes": build the health check that runs before any change.

## Decisions
- The profiler only **looks**: it never changes data (a test checks this).
- Every value is sorted into a pattern (plain number, currency, Indian/international/European grouping,
  K/L/Cr/M suffix, accounting negative, percent, ISO / slash / month-name date, boolean, NaN/Inf, text, empty).
  Nothing is converted yet. That's Step 5.
- Checks use the rule book: expected type, ranges, allowed values, the dataset date range and the locale date order.
- The report is a JSON-ready dict plus a short human-readable list of findings (error / warning / info).
- Known gap, on purpose: quantity `-999` in SALES_002 is not flagged, because returns are allowed
  (min −1000). The Step 7 rule `return_sign_consistency` catches it (negative quantity with positive sales).

## Simple explanation
Like a doctor's check-up before treatment: measure everything, write it down, treat nothing yet.
For example, it reports "4 dates are in the year 2035" and "8 product names differ only by spaces or
capital letters", but it doesn't fix them.

## Result on SALES_002 (Excel file)
Every planted problem was found with the exact count from the answer key: 4 dates in 2035, 4 non-numeric
prices, 4 discounts above 0.8, 4 exact plus 4 hidden duplicates, 12 missing values (3 columns), 8+8 spelling
variants, 4 Excel date numbers, 4+4 other date styles, 8 sales amounts with ₹ or K/L, 4 percent discounts,
4 accounting negatives.

## Technical explanation
- `profiling/patterns.py`: `classify()`, vectorized `str.fullmatch` per regex + `np.select` (first match
  wins). `slash_date_parts()` splits d/m/y text without interpreting it.
- `profiling/profiler.py`: `profile(df, cfg, metadata)`:
  header mapping (mapped / unmapped / missing required / mapped twice); exact and trim+case duplicates;
  per column: missing + markers used, unique, top values, pattern counts + examples, spaces; typed checks:
  numeric → needs_normalization, out_of_range, type_mismatch; date → possible Excel serials (20000–80000),
  ambiguous day/month, slash dates outside the date-range years; string → spelling variants (vs the most
  frequent spelling in each loose group, vectorized) and not-in-allowed-values.
  `write_report()` (JSON) and `summary_text()`.
- CLI: `python -m insightflow.profiling <file> <dataset_id> [--out report.json]`.
- Tests: `tests/test_profiling.py` (39): 27 pattern cases; SALES_002 counts equal the answer key for every
  issue type; no mutation; JSON round trip; missing/unmapped columns; works without a config; SALES_001
  checks. Total: 138 passing.

## Technical explanation
- `python -m venv .venv`, then `pip install -e ".[dev]"`: an editable install of the `src/` layout
  package, so `import insightflow` works from tests.
- `pyproject.toml`: package metadata, dependency ranges, pytest config.
- `requirements.txt`: exact pins from `pip freeze` for reproducibility.
- `.gitignore`: data folder contents are ignored (raw data may be private, outputs are generated);
  `.gitkeep` placeholders keep the empty folders in git.
- Python 3.14.4, pandas 3.1.1, pandera 0.36.0, pydantic 2.14.4, pytest 9.2.0.
